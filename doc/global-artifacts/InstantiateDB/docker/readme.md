# 💾 Configuração do Oracle Database 21c XE com Docker e DataGrip

Este guia explica como preparar um banco de dados **Oracle 21c Express Edition** local em **Docker**, configurar o DataGrip corretamente para aceder à PDB (`XEPDB1`) e criar manualmente o utilizador da aplicação (`APPUSER`).

---

## 🧩 1. Iniciar o Oracle 21c XE com Docker Compose

### Pré-requisitos

1. Ter o **Docker Desktop** instalado e a correr
2. Aceitar os termos da imagem oficial em [https://container-registry.oracle.com](https://container-registry.oracle.com) → `database/express`
3. Ter esta estrutura de ficheiros:

```
docker
├── docker-compose.yml
└── setup/
    └── init.sql
```

### 📄 `docker-compose.yml`

```yaml
version: '3.8'

services:
  oracle-xe:
    image: container-registry.oracle.com/database/express:latest
    container_name: oracle21c-xe
    ports:
      - "1521:1521"
      - "5500:5500"
    environment:
      - ORACLE_PWD=admin   # senha inicial para SYSTEM/SYS/PDBADMIN
    volumes:
      - oracle-xe-data:/opt/oracle/oradata
      - ./setup:/opt/oracle/scripts/setup   # scripts executados automaticamente
    healthcheck:
      test: ["CMD-SHELL", "/opt/oracle/checkDBStatus.sh > /dev/null 2>&1"]
      interval: 30s
      timeout: 10s
      retries: 30

volumes:
  oracle-xe-data:
```

### 📄 `setup/init.sql`

```sql
ALTER USER system IDENTIFIED BY admin CONTAINER=ALL;
ALTER USER system ACCOUNT UNLOCK CONTAINER=ALL;
```

---

## ▶️ 2. Subir o container

Dentro da pasta `oracle-xe`, execute:

```bash
docker-compose up -d
```

A criação da base pode demorar alguns minutos (4–8 min).
Quando o log mostrar:

```
#########################
DATABASE IS READY TO USE!
#########################
```

a base está pronta.

Verifique:

```bash
docker ps
```

Deve indicar o container `oracle21c-xe` com estado `(healthy)`.

---

## 🧠 3. Configurar o DataGrip

1. **File → Data Sources → Add → Oracle**
2. Em **General**:

    * **Host:** `localhost`
    * **Port:** `1521`
    * **Connection type:** `Service name`
    * **Service name:** `XEPDB1`
    * **User:** `system`
    * **Password:** `admin`
3. A URL deve ficar:

   ```
   jdbc:oracle:thin:@//localhost:1521/XEPDB1
   ```
4. Clique em **Test Connection** → deve aparecer *Oracle 21.3.0.0.0* ✅

![img.png](tutorial_datagrip.png)

## ⚙️ 4. Verificar se a PDB está aberta

Abra um terminal SQL (via `docker exec` ou DataGrip conectado como SYSTEM):

```sql
SELECT name, open_mode FROM v$pdbs;
```

Se `XEPDB1` estiver `MOUNTED`, abra-a:

```sql
ALTER PLUGGABLE DATABASE XEPDB1 OPEN;
ALTER PLUGGABLE DATABASE XEPDB1 SAVE STATE;
```

---

## 👤 5. Criar o utilizador da aplicação (`APPUSER`)

> [!important]
> Deve ser feito conectado à PDB `XEPDB1` com o utilizador `SYSTEM`

Ligue-se ao banco:

```bash
docker exec -it oracle21c-xe bash -lc "sqlplus system/admin@localhost:1521/XEPDB1"
```

E execute o script SQL abaixo:

```sql
CREATE USER appuser IDENTIFIED BY "YOURsTRONGpASSW0R$"
  DEFAULT TABLESPACE USERS
  TEMPORARY TABLESPACE TEMP
  QUOTA UNLIMITED ON USERS
  ACCOUNT UNLOCK;

GRANT CREATE SESSION TO appuser;
GRANT CREATE TABLE TO appuser;
GRANT CREATE SEQUENCE TO appuser;
GRANT CREATE VIEW TO appuser;
GRANT CREATE PROCEDURE TO appuser;
GRANT CREATE TRIGGER TO appuser;
```

> 🔒 Se vir `ORA-65096: nome de utilizador comum é inválido`,
> significa que ainda está no CDB root. Use:
>
> ```sql
> ALTER SESSION SET CONTAINER = XEPDB1;
> SELECT SYS_CONTEXT('USERENV','CON_NAME') FROM dual;
> ```

---

## 🧮 6. Confirmar ligação com o APPUSER

No DataGrip, configure nova conexão:

* **User:** `appuser`
* **Password:** a senha definida
* **Service:** `XEPDB1`

Teste a ligação e execute:

```sql
SELECT SYS_CONTEXT('USERENV','CON_NAME') FROM dual;
```

Resultado esperado:

```
XEPDB1
```

---

## 📂 7. Testar criação de tabelas

Conectado como `APPUSER`:

```sql
CREATE TABLE customers (
    id    NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name  VARCHAR2(200) NOT NULL,
    email VARCHAR2(320) UNIQUE
);

INSERT INTO customers(name, email)
VALUES ('Ana', 'ana@example.com');

SELECT * FROM customers;
```

## 🧹 8. Dropar tabelas com segurança

```sql
BEGIN
  EXECUTE IMMEDIATE 'DROP TABLE customers CASCADE CONSTRAINTS PURGE';
EXCEPTION
  WHEN OTHERS THEN
    IF SQLCODE != -942 THEN RAISE;
  END IF;
END;
/
```

## ⚠️ 9. Erros comuns

| Erro                  | Causa                              | Solução                                        |
| --------------------- | ---------------------------------- | ---------------------------------------------- |
| ORA-65096             | Usuário criado no CDB root         | `ALTER SESSION SET CONTAINER = XEPDB1`         |
| ORA-12514 / ORA-12505 | Listener não reconhece o serviço   | Use `Service name = XEPDB1`                    |
| ORA-01017             | Usuário/senha incorretos           | Confirmar `appuser@XEPDB1`                     |
| ORA-01950             | Sem quota no tablespace            | `ALTER USER appuser QUOTA UNLIMITED ON USERS;` |
| ORA-00933             | Uso de `IF EXISTS` em `DROP TABLE` | Use o bloco PL/SQL acima                       |
